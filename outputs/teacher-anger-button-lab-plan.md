# 교사용 분노버튼 수업 버전 기획안

## 방향 전환

학생용 `분노버튼 측정소`는 학생이 자신의 분노 유발 패턴을 살펴보고, 조절 버튼과 마음 안정 캐릭터를 만드는 자기이해 활동이었다.

교사용 버전은 학생에게 검사를 시키는 도구가 아니라, 교사가 수업을 설계하고 안전하게 운영하도록 돕는 수업 설계 도구로 바꾸는 것이 좋다.

제안 이름:

- 분노버튼 수업 설계실
- 마음 안정 캐릭터 수업 코치
- 감정 버튼 수업 메이커

가장 적합한 방향은 `분노버튼 수업 설계실`이다. 학생용 앱의 세계관은 유지하되, 교사가 차시, 학급 분위기, 활동 방식, 결과물 형태를 조정할 수 있다는 느낌이 분명하다.

## 핵심 사용자

- 사회정서교육, 생활교육, 창체, 상담 연계 수업을 준비하는 교사
- 중학생 대상 감정 조절 수업을 처음 설계하는 교사
- AI 이미지 생성이나 캐릭터 활동을 수업에 넣고 싶지만 안전한 진행 구조가 필요한 교사
- 학생 활동 결과물을 학급 게시, 활동지, 발표, 포트폴리오로 연결하고 싶은 교사

## 교사용 버전의 핵심 가치

1. 수업 준비 시간을 줄인다.
2. 학생이 자기 노출을 과하게 하지 않도록 안전 장치를 제공한다.
3. 교사가 바로 읽을 수 있는 진행 멘트와 질문을 제공한다.
4. 디지털 수업, 종이 활동지 수업, AI 없는 수업으로 변환할 수 있다.
5. 학생 결과물을 평가가 아니라 자기이해와 조절 전략으로 연결한다.

## 앱의 새로운 구조

### 1. 수업 조건 입력

교사가 먼저 수업 상황을 고른다.

- 대상: 초등 고학년, 중1, 중2, 중3, 고등
- 수업 시간: 45분, 50분, 90분 블록, 2차시
- 수업 환경: 개인 기기 있음, 모둠 기기만 있음, 기기 없음
- AI 이미지 생성 사용 여부: 사용, 프롬프트만 작성, 사용하지 않음
- 학급 분위기: 안정적, 장난이 많은 편, 갈등 이슈가 있음, 자기표현을 어려워함
- 결과물 형태: 활동지, 이미지 카드, 발표용 슬라이드, 교실 게시용 카드

### 2. 수업 목표 선택

교사가 수업의 중심 목표를 고른다.

- 감정 알아차리기
- 분노 유발 상황 이해하기
- 내 욕구와 경계 이해하기
- 조절 전략 고르기
- 마음 안정 캐릭터 만들기
- 친구의 감정을 존중하는 말 연습하기

선택한 목표에 따라 도입 질문, 활동 순서, 정리 문장이 달라진다.

### 3. 활동 흐름 생성

앱이 교사용 수업 흐름을 자동으로 구성한다.

기본 45분 예시:

1. 도입 5분: 분노는 없애야 하는 감정이 아니라 신호라는 관점 안내
2. 탐색 10분: 나의 분노버튼 상황 카드 고르기
3. 분석 10분: 버튼 뒤에 있는 욕구와 경계 찾기
4. 조절 8분: 나에게 맞는 마음 안정 버튼 3개 고르기
5. 제작 8분: 마음 안정 캐릭터와 한마디 만들기
6. 정리 4분: 오늘의 나 사용 설명서 한 줄 쓰기

### 4. 교사용 진행 멘트 생성

교사가 그대로 읽거나 조금 바꿔 쓸 수 있는 멘트를 제공한다.

예시:

> 오늘 활동은 누가 더 화를 잘 내는지 알아보는 시간이 아닙니다. 내 마음이 어떤 상황에서 신호를 보내는지 알아차리고, 그때 나를 도와줄 방법을 찾아보는 시간입니다.

> 친구 이름이나 실제 사건을 자세히 쓰지 않아도 됩니다. 오늘은 누군가를 평가하는 시간이 아니라, 나를 더 안전하게 이해하는 시간입니다.

### 5. 학생 활동 자료 생성

교사가 선택한 조건에 맞춰 학생용 자료를 출력한다.

- 1쪽 활동지
- 모둠 활동 카드
- AI 프롬프트 작성지
- 마음 안정 캐릭터 결과 카드
- 칠판 안내 문구
- 수업 후 성찰 질문

### 6. 민감 상황 대응 카드

교사용 버전에는 반드시 상황 대응 카드가 있어야 한다.

예시 상황:

- 학생이 실제 친구 이름을 쓰려고 할 때
- 특정 학생을 놀리는 분위기가 생길 때
- 학생이 가정 문제나 깊은 상처를 직접 적으려 할 때
- 점수를 비교하며 장난치는 학생이 있을 때
- 활동을 장난스럽게만 받아들이는 학생이 있을 때

각 상황마다 `교사 멘트`, `즉시 조정`, `수업 후 확인`을 제공한다.

## 학생용 앱과 달라져야 할 점

| 학생용 앱 | 교사용 버전 |
| --- | --- |
| 학생이 직접 25문항에 답한다 | 교사가 문항형, 카드형, 토론형 중 선택한다 |
| 개인 결과 카드 중심 | 수업 흐름, 활동지, 진행 멘트 중심 |
| 캐릭터 프롬프트 생성 | 프롬프트 지도안과 예시 프롬프트 생성 |
| 자기 결과 저장 | 교사용 수업 패키지 저장 |
| 감정 유형 확인 | 학급 안전 운영과 성찰 질문 제공 |

## 교사용 버전의 주요 화면

### 시작 화면

제목:

`분노버튼 수업 설계실`

설명:

`학생들이 분노를 평가받는 대신, 감정 신호를 이해하고 자신에게 맞는 안정 전략을 찾도록 돕는 수업을 설계합니다.`

버튼:

- 새 수업 만들기
- 45분 빠른 수업
- 기기 없는 활동지 수업
- AI 캐릭터 활동 수업

### 수업 설정 화면

교사가 수업 조건을 빠르게 고른다.

추천 UI:

- 학년 선택: 세그먼트 버튼
- 수업 시간: 카드형 선택
- 기기 환경: 아이콘 선택
- 학급 분위기: 체크박스
- 결과물: 체크박스

### 수업 흐름 화면

왼쪽에는 시간표형 수업 흐름, 오른쪽에는 교사용 멘트와 준비물이 표시된다.

교사는 각 활동을 켜고 끌 수 있다.

- 도입
- 버튼 탐색
- 욕구 찾기
- 조절 전략
- 캐릭터 만들기
- 나눔
- 정리

### 자료 생성 화면

생성 가능한 자료:

- 교사용 지도안
- 학생 활동지
- 모둠 카드
- 칠판 안내문
- AI 이미지 프롬프트 예시
- 수업 후 성찰 문항

### 최종 패키지 화면

최종 결과는 `수업 패키지` 형태로 제공한다.

포함 항목:

- 수업 제목
- 수업 목표
- 시간별 흐름
- 교사용 진행 멘트
- 학생 활동지 문구
- 안전 안내 문구
- 선택한 활동 자료
- AI 프롬프트 정책

버튼:

- 지도안 복사
- 활동지 복사
- 프롬프트 예시 복사
- 인쇄용 페이지 열기
- 처음부터

## 활동 방식 변형

### A. 45분 기본형

감정 버튼을 짧게 탐색하고, 조절 전략과 캐릭터 한마디까지 완성한다.

### B. 90분 확장형

모둠 대화와 캐릭터 제작 시간을 늘린다. 학생들이 서로의 결과를 발표하지 않고, 선택적으로 공유하게 한다.

### C. 기기 없는 활동지형

교사가 출력한 상황 카드와 활동지를 사용한다. AI 이미지는 사용하지 않고 캐릭터를 손그림으로 만든다.

### D. AI 프롬프트형

학생이 글자 없는 마음 안정 캐릭터 이미지를 만들 수 있도록 프롬프트를 작성한다. 이미지 안에 한글, 이름, 학교명, 실제 사건은 넣지 않도록 안내한다.

### E. 교사 연수형

교사가 학생 입장에서 활동을 먼저 해보고, 이후 수업 운영상의 주의점과 변형 방안을 논의한다.

## 안전 설계 원칙

교사용 버전에서는 다음 원칙을 화면에 계속 반영한다.

1. 진단이나 심리검사가 아니라 수업 활동임을 분명히 한다.
2. 학생의 실제 이름, 친구 이름, 교사 이름, 가족 문제를 쓰지 않도록 한다.
3. 결과를 점수 비교나 성격 낙인으로 사용하지 않는다.
4. 학생이 공유 범위를 선택할 수 있게 한다.
5. 힘든 감정이 드러날 때 연결할 수 있는 도움 자원을 안내한다.
6. 교사가 수업 중 멈춤, 개별 확인, 상담 연계를 판단할 수 있게 돕는다.

## 교사용 콘텐츠 예시

### 도입 질문

- 화가 난다는 것은 나쁜 사람이라는 뜻일까?
- 분노가 나를 지키려고 보내는 신호라면, 어떤 신호일까?
- 같은 상황에서도 사람마다 다르게 화가 나는 이유는 무엇일까?

### 버튼 뒤 욕구 질문

- 이 상황에서 내가 바란 것은 무엇이었을까?
- 내가 존중받고 싶었던 부분은 무엇일까?
- 내가 지키고 싶었던 경계는 무엇일까?
- 다음에 비슷한 상황이 오면 나를 도와줄 작은 행동은 무엇일까?

### 정리 문장 틀

- 나는 `____` 상황에서 마음의 신호가 커질 수 있다.
- 그때 내 마음은 `____`을/를 바라고 있을 수 있다.
- 나를 도와주는 안정 버튼은 `____`이다.
- 내 마음 안정 캐릭터는 나에게 `____`라고 말해준다.

## AI 캐릭터 활동 지도 원칙

- 이미지 안에는 글자, 이름, 로고를 넣지 않는다.
- 캐릭터는 학생 자신을 그대로 닮게 만들 필요가 없다.
- 동물, 별, 구름, 로봇, 식물처럼 상징적 캐릭터를 허용한다.
- 캐릭터의 한마디는 이미지가 아니라 결과 카드나 활동지에 따로 적는다.
- 학생이 실제 경험을 지나치게 자세히 입력하지 않도록 한다.

교사용 안내 문구:

> AI에게 내 실제 이야기 전체를 알려줄 필요는 없습니다. 오늘은 나를 도와주는 분위기와 캐릭터의 모습을 만드는 활동입니다.

## 구현 형태 제안

기존 학생용 앱이 Next.js, TypeScript, Tailwind CSS 기반이므로 교사용 버전도 같은 구조로 확장하는 것이 자연스럽다.

단, 화면 성격은 학생용보다 더 조용하고 실무적인 톤이 좋다.

디자인 방향:

- 색상: 부드러운 민트, 아이보리, 연한 남색, 살구색 포인트
- 분위기: 귀엽지만 교사용 도구답게 정돈된 느낌
- 첫 화면: 랜딩 페이지보다 바로 수업 설정을 시작하는 작업형 화면
- 주요 UI: 체크박스, 세그먼트 버튼, 시간표형 플로우, 복사 버튼, 인쇄 버튼

## 한 줄 콘셉트

`분노버튼 수업 설계실`은 교사가 학생들의 분노를 판단하지 않고, 감정 신호를 안전하게 탐색하며 마음 안정 캐릭터 활동까지 연결하는 수업 패키지를 빠르게 만드는 도구다.
