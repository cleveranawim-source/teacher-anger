# 교사 대상 분노버튼과 마음 안정 캐릭터 만들기 수업 기획안

## 핵심 방향

이 수업은 교사가 학생을 지도하기 위한 도구 사용법을 배우는 시간이 아니라, 교사 자신이 한 명의 참여자로서 자신의 분노버튼을 탐색하고 마음 안정 캐릭터를 만들어보는 사회정서교육 연수형 수업이다.

학생용 `분노버튼 측정소`의 구조는 유지하되, 문항과 언어를 교사의 학교생활 맥락에 맞게 바꾼다. 교사는 자신의 감정 신호를 살펴보고, 교직 생활에서 자주 눌리는 분노버튼과 그 뒤에 있는 욕구를 확인한 뒤, 나를 도와주는 안정 전략과 캐릭터를 만든다.

제안 이름:

- 교사의 분노버튼 연구소
- 선생님의 마음 안정 캐릭터 만들기
- 교사 마음 버튼 워크숍
- 나를 지키는 교사 마음 설명서

가장 적합한 제목은 `교사의 분노버튼 연구소`다. 너무 치료나 상담처럼 보이지 않으면서도, 교사가 자신의 반응을 관찰하고 이해하는 활동이라는 느낌이 살아 있다.

## 수업 목표

1. 교직 생활에서 나의 분노가 자주 올라오는 상황을 알아차린다.
2. 분노 뒤에 있는 욕구, 경계, 기대, 피로를 구분해 본다.
3. 나에게 필요한 마음 안정 전략을 선택한다.
4. 나를 도와주는 마음 안정 캐릭터와 자기 코칭 문장을 만든다.
5. 학생의 감정 조절 수업을 지도하기 전에, 교사 자신의 경험을 통해 활동의 의미를 체감한다.

## 참여자 안내 문구

> 이 활동은 교사의 성격을 판단하거나 평가하는 시간이 아닙니다. 교직 생활 속에서 내 마음이 어떤 상황에 특히 강하게 반응하는지 살펴보고, 나를 조금 더 안전하게 돌보는 방법을 찾아보는 시간입니다.

> 실제 학생 이름, 학부모 이름, 동료 교사 이름, 학교명처럼 개인을 특정할 수 있는 정보는 쓰지 않습니다. 구체적인 사건보다 그때 내 마음이 무엇을 필요로 했는지에 초점을 둡니다.

## 전체 흐름

### 1. 도입: 교사의 분노는 무엇을 알려주는가

시간: 10분

핵심 메시지:

- 교사의 분노는 부끄러운 감정이 아니라, 소진과 경계 침범을 알려주는 신호일 수 있다.
- 분노를 없애는 것이 목표가 아니라, 분노가 알려주는 필요를 알아차리는 것이 목표다.
- 교사가 자기 감정을 안전하게 다룰수록 학생 감정도 덜 방어적으로 바라볼 수 있다.

도입 질문:

- 최근 학교에서 마음이 확 올라왔던 순간은 언제였나?
- 그때 나는 화가 났던 걸까, 억울했던 걸까, 지쳤던 걸까?
- 내 분노는 나에게 무엇을 지켜달라고 말하고 있었을까?

### 2. 교사의 분노버튼 탐색

시간: 15분

학생용의 5가지 버튼을 교사 맥락으로 재구성한다.

| 버튼 | 교사 맥락 의미 |
| --- | --- |
| 무시 버튼 | 내 말, 전문성, 수업 준비, 생활지도 노력이 가볍게 여겨진다고 느낄 때 눌리는 버튼 |
| 억울함 버튼 | 책임은 커지는데 상황과 맥락이 공정하게 보이지 않을 때 눌리는 버튼 |
| 비교 버튼 | 다른 교사, 다른 학급, 성과, 민원 대응 방식과 비교될 때 눌리는 버튼 |
| 경계침범 버튼 | 쉬는 시간, 사생활, 감정 노동, 업무 범위의 경계가 침범된다고 느낄 때 눌리는 버튼 |
| 통제 버튼 | 교육적 판단이나 자율성이 제한되고 지시만 늘어난다고 느낄 때 눌리는 버튼 |

활동 방식:

- 각 문항을 읽고 0점부터 4점까지 표시한다.
- 점수는 비교하지 않는다.
- 가장 높은 버튼은 “나를 힘들게 하는 문제점”이 아니라 “내 마음이 자주 보내는 신호”로 해석한다.

### 3. 버튼 뒤의 욕구 찾기

시간: 15분

각 버튼 뒤에 있는 욕구를 연결한다.

| 버튼 | 뒤에 있을 수 있는 욕구 |
 --- | --- |
| 무시 버튼 | 존중, 인정, 경청, 전문성 존중 |
| 억울함 버튼 | 공정함, 맥락 이해, 책임의 균형 |
| 비교 버튼 | 고유성 인정, 과정 인정, 충분한 시간 |
| 경계침범 버튼 | 휴식, 안전한 거리, 업무 경계, 사생활 |
| 통제 버튼 | 자율성, 신뢰, 선택권, 교육적 판단권 |

성찰 문장:

- 내가 화가 났던 이유는 단순히 예민해서가 아니라 `____`이/가 필요했기 때문일 수 있다.
- 내 마음은 그 순간 `____`을/를 지키고 싶어 했다.
- 앞으로 비슷한 상황에서 나는 `____`라는 신호를 먼저 알아차리고 싶다.

### 4. 나의 마음 안정 버튼 고르기

시간: 10분

교사에게 맞는 안정 전략을 고른다.

선택지 예시:

- 90초 멈춤: 바로 반응하지 않고 몸의 긴장부터 낮추기
- 문장 바꾸기: “왜 또 이래?”를 “지금 내가 지키고 싶은 것은 무엇이지?”로 바꾸기
- 경계 문장 준비: “지금 바로 답하기 어렵습니다. 확인 후 다시 말씀드리겠습니다.”
- 짧은 회복 루틴: 물 마시기, 창밖 보기, 복도 걷기, 호흡 세 번
- 동료 연결: 안전한 동료에게 사실과 감정을 분리해 말하기
- 기록 후 거리두기: 바로 보내지 않고 메모장에 먼저 쓰기
- 감각 안정: 음악, 향, 따뜻한 차, 손 마사지, 자연 이미지 보기
- 업무 경계 세우기: 답변 가능 시간, 상담 가능 범위, 기록 원칙 정하기

### 5. 마음 안정 캐릭터 만들기

시간: 20분

교사가 자신을 도와주는 캐릭터를 만든다. 캐릭터는 실제 교사 자신의 외모를 닮을 필요가 없다.

입력 항목:

- 캐릭터 이름
- 캐릭터 형태: 사람형, 동물 의인화, 상상 캐릭터, 자연물 캐릭터, 작은 도구 캐릭터
- 색감: 차분한 녹색, 따뜻한 살구색, 밝은 노랑, 깊은 남색, 부드러운 회색 등
- 캐릭터 성격: 침착한, 단단한, 유머 있는, 조용히 지켜보는, 현실적인, 다정한
- 캐릭터가 나에게 해주는 한마디

교사용 캐릭터 한마디 예시:

- 지금 바로 완벽하게 해결하지 않아도 괜찮아.
- 네가 지키고 싶었던 것은 소중한 경계였어.
- 잠깐 멈춘다고 책임을 피하는 것은 아니야.
- 오늘의 너는 충분히 애썼어.
- 반응하기 전에 네 마음부터 확인해도 돼.
- 모든 것을 혼자 감당하지 않아도 돼.

## 교사용 분노버튼 문항 예시

각 문항은 0점부터 4점까지 선택한다.

0점: 거의 그렇지 않다  
1점: 조금 그렇다  
2점: 보통이다  
3점: 꽤 그렇다  
4점: 매우 그렇다

### 무시 버튼

1. 내가 충분히 설명했는데도 내 말이 가볍게 넘어갈 때 마음이 확 올라온다.
2. 수업이나 생활지도를 위해 애쓴 과정이 당연한 일처럼 여겨질 때 화가 난다.
3. 내 전문적 판단보다 즉각적인 요구나 민원이 더 우선되는 것처럼 느껴질 때 힘들다.
4. 학생이나 보호자가 내 말을 제대로 듣지 않는다고 느낄 때 감정이 커진다.
5. 내가 보이지 않는 곳에서 한 노력이 인정받지 못한다고 느낄 때 마음이 상한다.

### 억울함 버튼

1. 여러 사정이 있었는데 결과만 보고 책임을 묻는다고 느낄 때 화가 난다.
2. 내가 감당할 수 있는 범위를 넘는 일이 당연하게 주어질 때 억울하다.
3. 문제의 원인은 복잡한데 교사 개인의 책임처럼 느껴질 때 답답하다.
4. 충분히 설명할 기회 없이 오해받는다고 느낄 때 마음이 크게 흔들린다.
5. 공정하지 않은 기준으로 판단받는다고 느낄 때 감정이 올라온다.

### 비교 버튼

1. 다른 교사나 다른 학급과 비교되는 말을 들을 때 불편하다.
2. 학생의 변화 과정보다 눈에 보이는 결과만 평가받는다고 느낄 때 힘들다.
3. 나의 방식이 존중받기보다 더 빠르고 눈에 띄는 방식과 비교될 때 지친다.
4. 내가 할 수 있는 만큼 하고 있는데 부족하다는 메시지를 받을 때 화가 난다.
5. 교사마다 상황이 다른데 같은 기준으로 비교된다고 느낄 때 마음이 상한다.

### 경계침범 버튼

1. 쉬는 시간이나 퇴근 후에도 계속 응답해야 한다고 느낄 때 부담이 커진다.
2. 업무 범위를 넘어서는 감정 노동이 반복될 때 화가 난다.
3. 내 사적인 시간과 공간이 존중받지 못한다고 느낄 때 예민해진다.
4. 학생이나 보호자의 요구가 내 한계를 넘어선다고 느낄 때 마음이 닫힌다.
5. 거절하거나 미루면 무책임한 사람처럼 보일까 봐 부담을 느낀다.

### 통제 버튼

1. 내 교육적 판단보다 지시나 절차만 강조될 때 답답하다.
2. 수업과 생활지도에서 선택권이 줄어든다고 느낄 때 의욕이 떨어진다.
3. 신뢰받기보다 계속 확인받는다고 느낄 때 화가 난다.
4. 현장의 맥락을 모르는 결정이 내려올 때 무력감을 느낀다.
5. 내가 중요하다고 생각하는 교육 방향을 펼치기 어렵다고 느낄 때 속상하다.

## 결과 카드 구성

최종 결과물은 교사 개인의 `마음 회복 카드`로 만든다.

포함 내용:

- 나의 대표 분노버튼
- 버튼 뒤의 핵심 욕구
- 나의 마음 안정 버튼 3개
- 마음 안정 캐릭터 이름
- 캐릭터가 해주는 한마디
- AI 이미지 생성 프롬프트
- 다음 주에 실천할 작은 회복 행동 1가지

결과 카드 제목 예시:

`나를 지키는 교사 마음 설명서`

## AI 이미지 프롬프트 정책

학생용 앱과 마찬가지로 이미지 안에 문자를 넣지 않는다. 교사 연수에서도 개인정보와 학교 정보가 들어가지 않도록 안내한다.

한국어 프롬프트 예시:

`차분하고 단단한 분위기의 마음 안정 캐릭터를 그려주세요. 캐릭터는 교직 생활에서 지친 사람에게 조용히 힘을 주는 듯한 표정과 자세를 가지고 있습니다. 색감은 {색감}이고, 캐릭터 형태는 {형태}입니다. 말풍선, 글자, 로고, 학교명, 이름은 이미지 안에 넣지 마세요.`

영어 프롬프트 예시:

`Create a calm and grounded emotional support character for a teacher. The character should look as if it is quietly encouraging someone who has had a difficult school day. Use a {color mood} color palette and make it a {character type}. Express care through facial expression, posture, and mood. Do not include speech bubbles, text, letters, logos, school names, or real names.`

## 90분 연수 흐름 예시

1. 도입 10분: 교사의 분노를 신호로 바라보기
2. 분노버튼 체크 15분: 개인별 문항 응답
3. 결과 해석 10분: 대표 버튼과 욕구 확인
4. 짝 대화 10분: 공유 가능한 범위에서만 이야기하기
5. 안정 전략 선택 10분: 나에게 맞는 회복 루틴 고르기
6. 캐릭터 설계 15분: 이름, 형태, 색감, 한마디 만들기
7. 프롬프트 생성 10분: AI 이미지 생성용 문장 완성
8. 정리 10분: 나를 지키는 교사 마음 설명서 작성

2. 분노버튼 체크 10분
3. 대표 버튼 확인 5분
4. 안정 버튼 선택 10분

6. 정리 5분

## 수업 진행 시 주의점

1. 교사 개인의 실제 사건을 자세히 공유하도록 요구하지 않는다.
2. 점수나 버튼 유형을 공개 비교하지 않는다.
3. 특정 학생, 학부모, 동료를 비난하는 방향으로 흐르지 않게 한다.
4. “교사는 화내면 안 된다”가 아니라 “교사도 감정 신호를 돌볼 필요가 있다”는 관점을 유지한다.
5. 마음 안정 캐릭터는 가볍고 창의적인 활동처럼 보이지만, 실제로는 자기 코칭 문장을 만드는 과정임을 안내한다.

| 친구, 장난, 비교, 통제 상황 중심 | 수업, 생활지도, 민원, 업무, 경계, 자율성 중심 |

## 한 줄 콘셉트

`교사의 분노버튼 연구소`는 교사가 자신의 분노를 부끄러운 반응이 아니라 마음의 신호로 이해하고, 교직 생활에서 자신을 지키는 안정 전략과 마음 회복 캐릭터를 만드는 참여형 연수 수업이다.
