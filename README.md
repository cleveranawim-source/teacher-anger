# 선생님의 분노버튼 연구소

교사가 직접 자신의 분노버튼을 살펴보고, 마음 안정 버튼과 마음 안정 캐릭터를 만들어 보는 참여형 연수 앱입니다.

## 실행

`index.html`을 브라우저에서 열면 앱으로 이동합니다.

직접 열기:

`outputs/teacher-anger-button-lab-app.html`

## 주요 기능

- 교사용 25문항 분노버튼 체크
- 대표 분노버튼과 버튼 뒤 욕구 확인
- 마음 안정 버튼 3개 선택
- 마음 안정 캐릭터 만들기
- 한국어/영어 AI 이미지 생성 프롬프트 생성
- 마음 설명서 복사, 인쇄, PNG 저장
